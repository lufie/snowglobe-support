# 雪景球 · 私隱與隱私政策

[使用支援](SUPPORT.md) · [私隱與隱私政策](PRIVACY.md) · [Languages](../README.md)

雪景球以系統選圖工具讀取你選擇的相片。景深分析與場景製作在 iPhone 上完成。若原始檔在 iCloud 照片，Apple 可能在選取時下載它。你可用 Apple WatchConnectivity 將成品傳到自己的配對手錶。

手錶使用腕部動作改變視角與揚起微粒。App 不保留動作紀錄，也沒有帳戶、開發者相片伺服器、廣告或分析 SDK。

草稿和最近傳送的場景會保留於你的裝置。在 iPhone 工作室可移除草稿。在兩部裝置刪除雪景球即可清除 App 保留的副本，「照片」中的原始檔仍會保留。你可停止選取或傳送相片，並在系統設定管理出現的動作權限。

你寄出支援郵件時，我們會使用你的地址和來信內容處理請求。你可用同一地址要求存取或刪除該往來紀錄。本頁由 GitHub 託管，GitHub 依照自己的隱私聲明處理網站存取。
