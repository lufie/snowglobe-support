# 雪景球 · 隐私政策

[使用支持](SUPPORT.md) · [隐私政策](PRIVACY.md) · [Languages](../README.md)

雪景球用系统选图器读取你选择的照片。景深分析和场景制作在 iPhone 上进行。如果原片在 iCloud 照片中，选图时可能由 Apple 下载原片。你可以通过 Apple WatchConnectivity 把生成的场景发送到自己的配对手表。

手表读取腕部动作以改变视角和扬起微粒，App 不保存运动历史。App 无账户系统、开发者照片服务器、广告或分析 SDK。

草稿和最近传送的场景保存在你的设备上。可在手机工坊移除草稿。在手机与手表上卸载雪景球，可清除 App 保留的副本，相册原图会保留。你可随时停止选图或传送，并在系统设置中管理显示的运动权限。

如果你发邮件求助，我们会使用来信地址和你提供的内容处理请求。可通过同一地址申请访问或删除该往来记录。本页由 GitHub 托管，访问记录由 GitHub 按其隐私声明处理。
