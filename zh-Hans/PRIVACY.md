# 雪景球 · 隐私政策

[使用支持](SUPPORT.md) · [隐私政策](PRIVACY.md) · [Languages](../README.md)

只有你选中的照片才会用来制作场景。景深分析和背景补图都在 iPhone 上完成，照片不会上传到开发者的服务器。只有你点「发送到手表」，做好的场景才会传到配对的 Apple Watch。如果原片在 iCloud 照片中，选取时可能由 Apple 下载原片。

手表读取腕部动作以改变视角和扬起微粒，App 不保存运动历史。App 无账户系统、开发者照片服务器、广告或分析 SDK。

你可以在 iPhone 上删除保存的场景，相册原图会保留。已发到手表的场景会单独保留，发送另一个场景可以替换它。要清除 App 在两台设备上保存的副本，可分别选择「删除 App」。

导入音乐时，iPhone 会处理你选择的音频。若 Apple Watch 已配对并装有雪景球，App 会尝试把可播放的音频副本传过去。购买与续订由 Apple 处理。

如果你发邮件求助，我们会使用来信地址和你提供的内容处理请求。可通过同一地址申请访问或删除该往来记录。本页由 GitHub 托管，访问记录由 GitHub 按其隐私声明处理。
